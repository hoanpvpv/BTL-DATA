| File | Mô tả |
|------|--------|
| **`crawlLinkBTL2.ipynb`** | Notebook dùng để **cào (crawl)** toàn bộ **link các xe ô tô** từ website nguồn. |
| **`crawlfullBTL2.ipynb`** | Cào toàn bộ **thông tin chi tiết của từng xe ô tô** từ danh sách link đã thu được. |
| **`clearDataBTL2.ipynb`** | Thực hiện **làm sạch dữ liệu**, **điền giá trị khuyết thiếu**, và **loại bỏ các giá trị ngoại lai (outliers)**. |
| **`knearestnbh.ipynb`** | Huấn luyện mô hình **K-Nearest Neighbors (KNN)** để **dự đoán giá xe ô tô**, bao gồm quá trình chia tập dữ liệu, chuẩn hóa, huấn luyện và đánh giá bằng các chỉ số như R², MAE, RMSE,... |
| **`car_links.csv`** | Lưu danh sách **các đường link xe ô tô** được thu thập từ giai đoạn crawling đầu tiên. |
| **`oto_full_data.csv`** | Lưu **toàn bộ dữ liệu ô tô thô (chưa làm sạch)**, bao gồm thông tin từ tất cả các link đã cào. |
